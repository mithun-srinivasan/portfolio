# Third-party notices

## Aceternity UI Dotted Glow Background

The hero background adds a native Canvas 2D dotted glow inspired by the [Aceternity UI Dotted Glow Background](https://ui.aceternity.com/components/dotted-glow-background) behavior. The page-wide dot grid and mesh remain plain CSS. The hero dots pulse independently, do not track the pointer, and render as a static field under reduced motion. No Aceternity source code or package is included.
